v1.0 wersja zatwierdzona przez promotora. Działająca na RPi 5:
1) kalendarz google, taski google, 
2) prognoza pogody, komunikacja z czujnikiem temperatury
3) wykrywanie twarzy,
4) asystent głosowy (nasłuchiwanie promptów, odpowiedź zaciągana z API, odczytanie odpowiedzi gTTS)
5) zdalny start przez czujnik PIR. 
6) Obrócony frontend (pion),
7) Sterowanie gestami przez kamerę (3 predefiniowane gesty)
8) Obsługa hotword (lustro, asystent, poczta, leki)
9) Automatyczny start programu przy uruchomieniu (2 osobne service). 
10) Wygaszanie ekranu.
11) Obsługa pudełka na leki IoT
12) Dodany drugi użytkownik

W repozytorium nie ma plików zawierających m.in. klucze API, dane użytkowników oraz plików środowiskowych.
